# Au Bon Goût Latino

Sitio web de una sola página para un food truck de comida latina en Burdeos, Francia. Presenta la historia del negocio, el menú, el origen de los ingredientes, el servicio de catering y un formulario de contacto, con un diseño moderno adaptado a la identidad de la marca.

## Secciones

- Portada con llamada a la acción.
- Nuestra historia.
- Menú.
- Origen de los ingredientes.
- Servicio de catering para eventos.
- Suscripción a novedades y ofertas.
- Contacto.

## Stack

- HTML5 semántico.
- Tailwind CSS (vía CDN).
- Font Awesome para iconografía.
- Tipografía Inter (Google Fonts).

Sin dependencias ni proceso de build: basta con abrir `home.html` en el navegador.
